01
INSERTION SORT

Insertion Sort

Insertion Sort works similarly to arranging cards in your hand. Each new element is picked and inserted into its correct position among the previously sorted elements.

How it works
  1. Start from the second element.
  2. Select the current element as the key.
  3. Compare it with elements on the left.
  4. Shift larger elements one position right.
  5. Insert the key into the correct position.
02
SHELL SORT

Shell Sort

Shell Sort is an improved version of insertion sorting. It first compares elements that are far apart and gradually reduces the gap.

How it works
  1. Choose an initial gap.
  2. Compare elements separated by the gap.
  3. Perform insertion-style sorting.
  4. Reduce the gap.
  5. Finish with a gap of 1.

Key Difference

Insertion Sort

Works directly with adjacent sorted elements.

VS
Shell Sort

Uses gaps to move elements faster over distance.

ALGORITHM LOGIC

Pseudocode

Read the algorithm logic before looking at the C code.

01
INSERTION SORT

Algorithm

INSERTION-SORT(A)

for i = 1 to length(A)-1

    key = A[i]

    j = i - 1

    while j >= 0 and A[j] > key

        A[j + 1] = A[j]

        j = j - 1

    A[j + 1] = key

end
02
SHELL SORT

Algorithm

SHELL-SORT(A)

gap = n / 2

while gap > 0

    for i = gap to n-1

        temp = A[i]

        j = i

        while j >= gap
              and A[j-gap] > temp

            A[j] = A[j-gap]

            j = j-gap

        A[j] = temp

    gap = gap / 2

end

C PROGRAMMING

C Implementation

See how the algorithms are implemented in C. 

#include <stdio.h>

void insertionSort(int arr[], int n)
{
    for (int i = 1; i < n; i++)
    {
        int key = arr[i];
        int j = i - 1;

        while (j >= 0 && arr[j] > key)
        {
            arr[j + 1] = arr[j];
            j--;
        }

        arr[j + 1] = key;
    }
}
#include <stdio.h>

void shellSort(int arr[], int n)
{
    for (int gap = n / 2;
         gap > 0;
         gap /= 2)
    {
        for (int i = gap; i < n; i++)
        {
            int temp = arr[i];
            int j = i;

            while (j >= gap &&
                   arr[j - gap] > temp)
            {
                arr[j] = arr[j - gap];
                j -= gap;
            }

            arr[j] = temp;
        }
    }
}
